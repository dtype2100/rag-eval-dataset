# 데이터 분석과 지원 판정

기존에 사용할 수 있는 도구를 조사한 뒤 필요한 분기만 읽고 적용한다. 새 입력 형식이라는 이유로 파서부터 설치하지 않는다.

| 입력 | 분석·근거 확보 | 지원 범위 판정 |
|---|---|---|
| 일반 문서/PDF/HTML | 페이지·제목·표·추출 문자 순서, 빈 페이지, 인코딩을 원본과 대조. 고정 추출물의 경로/offset과 원본 페이지 보존 | 읽을 수 있는 구간만 평가; 암호화/깨짐은 보류 |
| CSV/JSON/DB 내보내기 | 컬럼 의미·PK·단위·null·조인·집계·갱신 시점. 구조를 유지한 행/셀 또는 JSON 경로를 기록 | 스냅샷·정답 연산 검증 가능할 때 ready; 누락된 의미를 질의 |
| 코드/로그/대화 | 버전·파일/행, 시간·세션/스레드·화자·역할, 외부 참조를 보존 | 정적 자료로 답 가능한 과업과 실행 환경이 필요한 과업을 구분 |
| 스캔/이미지/도표 | OCR 문자뿐 아니라 축·범례·레이아웃·작은 글씨·단위를 원본 영역과 대조 | OCR/캡션만 있으면 파생 텍스트 과업으로 제한; 시각 질의는 원본 검토·입력 자산 필요 |
| 음성/영상 | 전사·발화자·시간 구간·비언어적 소리·화면 정보를 분리해 검토 | 전사만으로 소리/화면 이해까지 평가했다고 주장하지 않음 |
| 미지 바이너리/벡터 only | 원문·매핑·검증 가능한 기존 라벨 유무 확인 | 의미 근거 없으면 blocked; 임의 복원·상상 정답 금지 |

모든 입력에서 언어·출처·시점·접근권한·중복 집단을 조사한다. 본문 전수가 아니라 표본이면 표본 범위와 미조사 층을 명시한다.
변환 품질이 부족한 자료를 조용히 제외하지 말고 제외 수와 이유를 기록한다.

## 과업에 따른 정답 차이

- 정책·법규·제품 매뉴얼: 기준일과 우선 출처가 정답을 결정한다. 충돌을 해결할 기준이 없으면 clarify 또는 보류한다.
- 수치·표: 정답에 단위·기간·필터·허용 오차를 포함하고 근거 셀에서 연산을 재현한다.
- 탐색형 검색·이미지 유사 검색: 정답 문장보다 관련성 척도와 후보군·쿼리 지시가 중요하다. retrieval 계약을 사용한다.
- 외부 도구 실행/SQL/에이전트 행동: 검색 근거만으로 평가되지 않는 부분은 실행 가능한 환경·정답 상태를 별도로 확보하거나 범위를 제한한다.
- 무정답: 고정 코퍼스와 권한 범위에서 확인한다. 전수 확인이 불가능하면 “범위 내 미발견”의 한계와 판정 방법을 기록하고 확정적 부재와 구별한다.

## 대표성과 보안 경계

실제 사용자 질의가 없으면 문서 내용에서 생성한 질문은 문서 표현을 지나치게 닮을 수 있다.
다른 표현·약어·실제 언어를 포함하되 문서에 없는 전제를 정답에 넣지 않는다. 여러 검색 방식의 후보를 검토해 대체 근거와 혼동하기 쉬운 비관련 후보를 보완한다.

외부 전송 허용 범위가 확인되기 전에는 원본·질의를 외부 생성기/OCR 서비스에 보내지 않는다.
저장소 공개 권한은 실제 코퍼스·고객 질의 공개 권한과 다르다. 예제·행동 테스트에는 합성 자료를 쓴다.
